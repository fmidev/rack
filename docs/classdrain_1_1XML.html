Detailed Description

Base class for XML "nodes", to be data elements T for drain::Tree<T>

In derived classes, the values will be typically of enumeration type. The derived classes often reuse basic types, especially UNDEFINED, COMMENT, and CTEXT. In that case, the first enum values should "inherit" the integer values from this basic class with explicit enum value assigment. The first 10 values are recommended to be reserved for this purpose, allowing future extensions in this base class.
